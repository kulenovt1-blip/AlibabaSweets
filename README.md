# Али-Баба · Заявки (PWA)

## Файлы
- `index.html` — структура экрана
- `styles.css` — дизайн (токены бренда в начале файла)
- `app.js` — логика; настройки в блоке `CFG` вверху
- `manifest.webmanifest`, `sw.js` — установка на экран и офлайн
- `logo.jpg` — логотип

## Подключение Google Таблицы
1. Создайте таблицу. **Первая строка — заголовки**, порядок колонок строго такой:

| A категория | B название | C граммовка | D цена | E единица | F фото |
|---|---|---|---|---|---|
| Финики | Финики Ар-Раяна | 400г | 1500 | шт | https://… |
| Орехи | Грецкий орех | 1кг | 4200 | кг | |

   - Одна фасовка = одна строка.
   - Единица: `шт`, `кг` (разрешает дробное количество, например 2.5) или `кор`.
   - Цена — только число, без «₸» и пробелов.
2. **Файл → Поделиться → Опубликовать в интернете**. Слева выберите нужный лист, справа формат **CSV**, нажмите «Опубликовать» и скопируйте ссылку.
3. Вставьте ссылку в `app.js`: `SHEET_CSV: 'https://docs.google.com/…output=csv'`.
4. Изменили цену в таблице? Торговый открывает приложение → ⚙️ → «Обновить прайс». Публикация в интернете обновляется с задержкой в несколько минут.

### Фото
- Загрузите фото в Google Drive → ПКМ → «Настройки доступа» → **«Все, у кого есть ссылка»** → скопируйте ссылку в колонку F. Приложение само преобразует её в прямую.
- Подойдёт и любая прямая ссылка на картинку (`https://…/photo.jpg`).
- Нет ссылки или фото не открылось — показывается логотип.

## Публикация
1. GitHub Pages: создайте репозиторий, загрузите все файлы в корень, в Settings → Pages выберите ветку `main`. Или перетащите папку на netlify.com/drop.
2. Отправьте торговым ссылку. В Chrome на Android: меню ⋮ → «Добавить на главный экран».

## Номер оператора
Меняется в ⚙️ на каждом телефоне или по умолчанию в `CFG.OPERATOR`. Формат: `77001234567`.

## Иконка
Для красивой иконки заменить `logo.jpg` в `manifest.webmanifest` на квадратный PNG 512×512.
