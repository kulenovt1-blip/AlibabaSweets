# Али-Баба · Заявки (PWA) — инструкция

## Файлы
`index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `logo.jpg` — сайт.
`apps-script/Code.gs` — скрипт для таблицы (профили, история, магазины).
Ссылка на прайс, номер оператора и ключ уже вписаны в `app.js`.

## Шаг 1. Выложить сайт
1. Распакуйте архив.
2. Откройте netlify.com/drop и перетащите **всю папку** (index.html и остальные файлы внутри; папку `apps-script` можно оставить).
3. Откройте полученную ссылку `https://...netlify.app`. Страницу с компьютера двойным кликом открывать нельзя — прайс не загрузится.
4. Обновляете сайт — заменяйте **все** файлы сразу и обновляйте страницу дважды.

## Шаг 2. Прайс (Google Таблица)
Лист с колонками в таком порядке, первая строка — заголовки:
`Категория | Название | Граммовка | Цена (без НДС) | Цена (с НДС) | Единица (шт/кг/кор) | Фото`
1. Файл → Поделиться → Опубликовать в интернете → выберите **лист с прайсом** и формат **CSV** → Опубликовать.
2. Ссылку вставьте в `app.js` в `SHEET_CSV` (сейчас там ваша).
3. Изменили цены → в приложении ⚙️ → «Обновить прайс» (Google обновляет публикацию за несколько минут).
Фото: ссылка на файл в Google Drive с доступом «все, у кого есть ссылка», либо прямая ссылка на картинку.

## Шаг 3. Профили, история и магазины (Apps Script)
Без этого шага приложение работает, но без профилей и общей базы.
1. Откройте **ту же таблицу** → Расширения → Apps Script.
2. Удалите весь код в окне, вставьте содержимое `apps-script/Code.gs`. Нажмите 💾.
3. Нажмите **Развернуть → Новое развёртывание** → значок ⚙️ → тип **Веб-приложение**.
   - Выполнять от имени: **Я**
   - У кого есть доступ: **Все**
   Нажмите «Развернуть». Разрешите доступ (Google покажет предупреждение: «Дополнительно → Перейти → Разрешить»).
4. Скопируйте **URL веб-приложения** (заканчивается на `/exec`) и вставьте в `app.js`: `API_URL: 'https://script.google.com/macros/s/.../exec'`.
5. Загрузите сайт заново (Шаг 1).
6. В таблице появятся листы **Торговые**, **Магазины**, **Заявки**. На лист **Торговые** впишите имена торговых в колонку A (по одному в строке, под заголовком).
7. Откройте сайт: появится окно «Кто вы?» — выберите имя. Сменить профиль: ⚙️ → «Профиль».
Если меняете код в Apps Script: Развернуть → Управление развёртываниями → ✏️ → Версия: **Новая версия** → Развернуть (ссылка не меняется).
Ключ в `Code.gs` (`KEY`) и в `app.js` (`API_KEY`) должен совпадать (сейчас `3puq8z64`).
Публиковать в интернет нужно **только лист с прайсом**, иначе заявки станут публичными.

## Если что-то не работает
- **Красная плашка «Файлы сайта разных версий»** — загрузите все файлы заново.
- **«Страница открыта как файл (file://)»** — откройте сайт по https-ссылке с хостинга.
- **«Прайс не загружен…»** — ссылка не на CSV или лист не опубликован; проверьте ссылку в браузере: должен открываться текст с запятыми.
- **Жёлтая плашка «Не заполнена цена…»** — заполните цены у перечисленных товаров.
- **Окно «Кто вы?» пустое** — на листе «Торговые» нет имён, либо ключи не совпадают, либо `API_URL` неверный или скрипт не развёрнут как «Все».
